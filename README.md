# Tic-Tac-Toe

A simple and interactive Tic-Tac-Toe Android game developed using Java and XML in Android Studio.

## Features

- Two-player gameplay
- Simple and user-friendly interface
- Displays the winner or draw result
- Restart game option
- Responsive Android UI

## Technologies Used

- Java
- XML
- Android Studio

## How to Run

1. Clone or download the repository.
2. Open the project in Android Studio.
3. Let Gradle sync and build the project.
4. Run the app on an Android emulator or physical device.

## Project Purpose

This project was developed to practice Android application development, Java programming, XML-based UI design, and game logic implementation.
